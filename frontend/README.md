# Запуск проекта для разработки

**node.js v.22**


1. Запустить проект:
	`cd frontend`
	`npm i`
	`npm run dev`
2. Сделать туннель через tuna с помощью команды `tuna http localhost:{port}` либо достать JWT токен, запихнув `initData` из телеграма в куки и обновить страницу.
3. Полученный адрес добавить/заменить в боте @BotFather в соответствующем боте в Telegram в разделе Mini Apps. 

# Обработка ошибок при запросах
Для обработки ошибок сделал композабл `useFetchErrors`. Пример использования:
```
try { // some code }
catch (err)
{
    const { errors, statusCode } = useFetchErrors(err)
    console.log(errors.value);
    console.log(statusCode.value);
}

```

`errors` - объект с ошибками
`statusCode` - соответственно статус код

# Типизация
Для типов существует отдельная папка (`types`), в ней лежат файлы с типами. Каждому файлу соответствует область типов по названию файла.

В файле `common` - лежат типы для типизации запросов.

В папке типов лежит также папка `ui`, в ней находятся типы для типизации `props` в ui-компонентах.

# Модальные окна
Для управления модальными окнами есть стор в `/stores/popups.ts` и композабл `usePopusRegistry`.

Стор предоставляет имя активного модального окна, а так же функцию управления состоянием (открыто/закрыто).

В композабле `usePopupsRegistry` находится список имён модальных окон сопоставленный с компонентами.

### Типизация имен
Для типизации имён модальных окон существует файл `/types/ui/popups.ts`, в нём тип `PopupName`.

Чтобы добавить модальное окно надо:
1. Создать компонент окна в `/components/popups`.
2. Импортировать компонент в `usePopupsRegistry`.
3. Соотнести имя модального окна и компонента во внутренней переменной `popups`.
4. Добавить значение соответствующее имени модального окна в `/types/ui/popups.ts`.
### Управления модальными окнами
Управление модальными окнами производится с помощью функции `togglePopup` в сторе. Пример:
```

    const  {  togglePopup  }  =  usePopupsStore();

    // закрытие

    const  closePopup  =  ()  =>  togglePopup('AddInviteCode',  false);

    // или открытие

    const  openAddInviteCodePopup  =  ()  =>  togglePopup('AddInviteCode',  true);

```
