# Запуск проекта для разработки

**node.js v.22**

1. Запустить проект:
`cd frontend`
`npm i`
`npm run dev`

2. Сделать туннель через tuna с помощью команды `tuna http localhost:{port}`

3. Полученный адрес добавить/заменить в боте @BotFather в соответствующем боте в Telegram в разделе Mini Apps
